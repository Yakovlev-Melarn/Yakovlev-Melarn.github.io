# Портфолио бэкенд-разработчика

Статический сайт-портфолио в стиле терминала: тёмная тема, моноширинный шрифт, навигация через командную строку.

Чистый HTML/CSS/JS — без фреймворков, библиотек и сборщиков.

## Структура

```
portfolio/
├── index.html              — вся разметка
├── css/style.css           — терминальная тема
├── js/
│   ├── terminal.js         — ядро: парсинг команд, история, вывод
│   ├── typewriter.js       — эффект печатающегося текста
│   └── projects.js         — данные проектов
└── assets/
    ├── favicon.svg
    └── og-image.png
```

## Запуск

Откройте `index.html` в браузере.

## Деплой

GitHub Pages / Cloudflare Pages / Netlify — папка корня, без build.
